## Customization

### Change Products

Edit the products data in `src/App.tsx`:

```tsx
const products = [
  {
    id: 1,
    name: 'Product Name',
    category: 'category',
    price: 29.99,
    image: 'image-url.jpg',
    description: 'Product description'
  }
]
```

### Change Colors

Edit `tailwind.config.js`:

```js
theme: {
  extend: {
    colors: {
      primary: '#8B4513',
      secondary: '#D2691E',
      accent: '#F4A460'
    }
  }
}
```

### Deploy

```bash
npm install
npm run build
# Upload dist/ folder to any static host
```
